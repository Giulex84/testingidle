Privacy Policy

Last updated: September 8, 2026

Idle Realm Testnet is a Pi Network sandbox application used to test gameplay, persistent progress and Pi Testnet payment flows before a future Mainnet release.

1. Information we process

When you authenticate through the Pi Network SDK, the application may process your Pi username, Pi user identifier and wallet address made available through the permissions granted to the app. We also process gameplay progress, era state, payment identifiers, transaction status and technical information required to operate and secure the service.

2. How information is used

Information is used to authenticate players, restore persistent game progress, verify gameplay actions, process or recover Pi Testnet payments and rewards, prevent duplicate processing, diagnose failures and improve the game before Mainnet review.

3. Storage and service providers

The application is hosted on Vercel and uses Upstash Redis for persistent server-side game and transaction state. These providers may process technical metadata as part of operating their services. Pi authentication and payment functionality are provided through the Pi Network SDK and APIs.

4. Payment and wallet safety

Idle Realm does not request or store your wallet passphrase or private key. Payment approval, completion, recovery and reward deduplication are handled server-side using Pi payment identifiers and transaction state.

5. Testnet data and retention

This is a testing environment. Game state or Testnet data may be reset, migrated or removed as development requires. Test-Pi has no real-world value.

6. Sharing

We do not sell personal information or share it with third-party advertisers. Data is shared only with infrastructure and Pi ecosystem services as necessary to operate the application or where required by law.

7. Your choices

You may stop using the application at any time. Requests concerning stored application data can be made through the developer contact channel associated with the Pi application.
